# PFOS「不上班续航」MVP 规格（2025 口径）

状态：本地实现完成，待用户确认后部署
执行者：Codex 直接修改与复核
目标站点：现有 PFOS（`https://chenshushi.tech`）  
公开路径：`/runway`

## 1. 边界

- 不新建站点、域名、仓库或后端；复用 PFOS 现有域名和 `/runway` 公共路由。
- 只在浏览器内计算，不写入 localStorage、URL、日志或网络请求。
- 不修改 PFOS 债务引擎、数据模型、设置页和 Dashboard 业务逻辑。
- 结果是单人静态情景模拟，不构成辞职、投资或财务决策建议。
- 页面保持 Apple 风格：单列、简洁、移动端优先。

## 2. 用户路径

```text
外部内容或 PFOS 首页入口 → /runway
→ 输入本金 + 选择常住地区
→ 查看五档续航与休息天数对比
→ 可选进入现有 /wizard 债务体检
```

## 3. 地区集合

城市档（默认均需工作情景）：北京、上海、广州、深圳；成都、重庆、杭州、武汉、西安、苏州、郑州、南京、天津、长沙、东莞、宁波、佛山、合肥、青岛。

省级代表档：华东（浙江、江苏）、西北（甘肃、陕西）、东北（吉林）、西南（四川、贵州）、华南（广东、广西）、华中（山东、河南、湖南）。另有全国均值。

每条数据保留市/省/全国层级、2025 年年值、来源机构、发布日期、官方链接、最低工资值及最低工资来源。

## 4. 五档规则

```text
躺平过 = 当地最低工资 × 50%
省着过 = 当地最低工资 × 100%
日常过 = 当地官方月均消费
从容过 = 当地官方月均消费 × 130%
奢侈过 = 当地官方月均消费 × 300%
续航月数 = floor(可自由支配现金 ÷ 本档月消费额)
```

所有金额先转整数分；年消费数据为 2025 年公开年度城镇居民人均生活消费支出。最低工资取 2025 年适用的最低档月最低工资。

全国最低工资显示为各省 2025 年最低档标准按城镇人口加权估算，不是国家统一最低工资。

## 5. 休息时间对比

以“日常过”续航月数换算完整日数：`floor(月数 × 365 ÷ 12)`。

页面将其与 PFOS 场景基准“全国城镇职工加权平均全年实际休息中位值约 100 天”比较，仅展示中位值年数。该基准用于互动解释，不宣称是对每个人的法定休息承诺。

## 6. 页面信息架构

- 顶部：`PFOS · 20秒互动测算`、`不上班续航计算器`、输入现金和地区。
- 结果：五档卡片，日常过高亮；显示月消费额、完整月数。
- 对比：显示日常过现金天数及相当于多少个“全年休息年”。
- `这个结果怎么算`：集中展示本次数据、2025 年口径、最低工资来源、公式、全国权重说明、休息基准和限制；主结果区不重复堆方法论。
- CTA：仅在用户主动点击时进入现有 `/wizard`；未确认免责声明则返回 PFOS 首页。

## 7. 隐私与限制

默认单人、无工作收入、无投资收益、未计通胀；未纳入债务还款、房租/房贷、赡养抚养、保险、医疗和突发支出。金额和地区只在当前页面内计算，不上传、不保存。
