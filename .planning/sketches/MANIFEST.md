# Sketch Manifest

## Design Direction

延续 PFOS 现有的 Apple 风移动端视觉，将 Dashboard 从稀疏的数据摘要页重组为一份结论清楚、行动可执行、依据可追溯的连续体检报告。金额默认隐藏，风险色只强调关键判断，详细数据通过展开或既有模块查看。

## Reference Points

- 现有 PFOS Dashboard 的 Apple 风设计令牌
- 用户确认的《PFOS 体检报告》01–06 信息结构
- 现有债务清单、现金流、风险、行动和设置路由
